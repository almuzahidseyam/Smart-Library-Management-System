# Smart Library Management System

A Java Swing-based desktop application for managing a library's books, users, and borrowing records. 

## Features
- **User Authentication**: Login and Sign-up functionality for users.
- **Password Recovery**: Forgot password feature.
- **Database Integration**: Secure and local data storage using SQLite.

## Technologies Used
- **Language**: Java
- **GUI Framework**: Java Swing (NetBeans GUI Builder)
- **Database**: SQLite (LibraryNew.db)
- **Libraries**: 
  - sqlitejdbc-v056.jar (SQLite JDBC Driver)

## How to Run
1. Clone the repository to your local machine.
2. Open the project folder in **NetBeans IDE**.
3. Right-click the project in the Projects pane and select **Properties**.
4. Go to **Libraries** and ensure sqlitejdbc-v056.jar (located in the jar folder) is added to the Compile classpath.
5. Click **Run** to start the application.
